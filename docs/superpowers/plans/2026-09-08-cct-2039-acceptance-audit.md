## Deployment and operational boundary

Apply schema migrations before the new application code. The checked-in daily Vercel fallback processes at most 20 deliveries per run and does not provide prompt delivery. Use the documented trusted minute scheduler or always-on worker for prompt production delivery; the worker and authenticated endpoint are verified locally. No production scheduler credentials or hosting-plan changes were made in this task. See `docs/webhook-delivery.md` for cadence, deduplication, retry eligibility, secret rotation and retention.

Teams bot commands and automatic event notifications remain explicitly unavailable. Enabling them later requires a supported authenticated Bot Framework adapter and membership mapping, plus separate functional/protocol validation. Repository discovery retains its existing first-100-results provider limit; it does not permit selecting unverified metadata or bypassing admin checks.

The workspace's unrelated untracked planning files are preserved and excluded from the remediation commits.
